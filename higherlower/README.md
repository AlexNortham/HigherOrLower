# Project Info

* **Playable Build:** The executable (.exe) file is located in the **Releases** folder.
* **Source Code:** All code is located in the **Assets/Scripts** folder.

* **Decisions:** I made this project in the form I did as I wanted to create something reminiscent of games such as tabletop simulator, which contain multiple small replayable minigames. I wanted the experience to feel like you were playing these games in real life, so I decided to create an room environment with a camera positioned as if you were a player looking down at the table. It was important for this to have the cards appear and move in a semi realistic way, i.e. moving between a draw pile to the table and to a discard pile, and to simulate a player's "hand" by having an allocated location in front of the camera for cards to appear. I chose to reset the game in two different ways. Higher or lower fades out and back in to a fully reset table, and blackjack makes all cards jump back into the deck where they began.

* **Improvements:** At the moment, there are no mouse camera controls and you interact with buttons that appear on the screen by clicking on them. To improve the experience further, an implementation of camera controls and physical buttons in the room you can select would make the game feel more immersive. Additionally, the basic skeleton for the current games could be reused to implement a number of other card games, adding more variety. These new games could also open the door for the implementation of multiplayer, as both of the current games have you play against the "house" (the computer).
